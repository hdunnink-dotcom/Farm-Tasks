---
name: OpenAPI count schemas
description: Compatibility rule for numeric count fields generated by the workspace's Orval and Zod toolchain.
---

Use OpenAPI `number` rather than `integer` for generated non-negative count fields until the Zod generator and installed Zod major version are aligned. Enforce whole-number semantics in server calculations and tests.

**Why:** The current generator emits `zod.int()` for OpenAPI integers, but the installed Zod 3 API does not expose that constructor, so otherwise-valid codegen fails during the library typecheck.

**How to apply:** When adding generated response counts, use `type: number` with a minimum and keep the actual server values integral. Revisit this rule only after confirming generated integer schemas compile.
